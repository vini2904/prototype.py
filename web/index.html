NET-CASE-001 VLAN Layer 2 High
Human Review: Accepted

PC in VLAN 10 Cannot Ping Default Gateway

Observed Symptom:

Host PC-1 (192.168.10.50/24) cannot reach its default gateway 192.168.10.1 on Router R1. Link light on switch is amber.

Lab Topology:

PC-1 (Fa0/1) -> Switch SW1 (Gig0/1) -> Router R1 (Gig0/0.10 Subinterface)

Cisco IOS Show Commands

SW1# show vlan brief
VLAN Name                             Status    Ports
---- -------------------------------- --------- -------------------------------
1    default                          active    Fa0/2, Fa0/3, Fa0/4
10   Engineering                      active    
20   Sales                            active    Fa0/5, Fa0/6

SW1# show running-config interface FastEthernet0/1
interface FastEthernet0/1
 switchport mode access
 switchport access vlan 1
 spanning-tree portfast
✨

NetSage Hybrid Diagnosis

Confidence: 98%
⚙️ Deterministic Rule Engine: CHECK_VLAN_TRUNK

Access port VLAN configured on port 1 while host IP belongs to VLAN 10 subnet.

Root Cause Diagnosis

Access port FastEthernet0/1 is configured for default VLAN 1, while PC-1 has an IP in subnet 192.168.10.0/24 corresponding to VLAN 10.

Evidence Citation

SW1# show running-config interface FastEthernet0/1 -> 'switchport access vlan 1' while PC-1 is on 192.168.10.50.

Recommended Next Diagnostic Command

show interfaces FastEthernet0/1 switchport

Remediation Script (Cisco IOS)

SW1# configure terminal
SW1(config)# interface FastEthernet0/1
SW1(config-if)# switchport access vlan 10
SW1(config-if)# end
SW1# write memory
